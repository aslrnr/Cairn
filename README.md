# Cairn

A chill 2D platformer roguelike. Delve a ruin under a hill, find relics, come home, stack a stone.

No timers. Rest at cairns, go home whenever you like, and keep part of your gold when you fall.

## Play

Open `index.html` in a browser. The whole game is that one file, with no build step.

Once GitHub Pages is switched on for this repository (Settings, Pages, Source: GitHub Actions), every push to `main` publishes the game.

## Controls

- Move: `A` `D` or arrow keys
- Jump: `Space` or `W` (hold to glide)
- Strike: `F` or mouse click (hold down in the air to strike downward)
- Roll: `Q` or `Shift`
- Use: `E`
- Drink flask: `R`
- Look down: hold `S`. Drop through ledges: `S` + jump
- Pause: `Esc`. Sound: `M`

Gamepads work too.

## Notes

Progress is saved in the browser's local storage, so it is tied to the address the game is served from.
